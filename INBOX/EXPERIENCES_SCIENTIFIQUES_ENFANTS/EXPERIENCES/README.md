# EXPÉRIENCES — fiches candidates

Chaque activité proposée doit comporter : identifiant provisoire, phénomène, tranche d'âge indicative, matériel, durée, sécurité, question, hypothèses, observation attendue, explication rigoureuse, explication enfant, limites, sources et vérification de compréhension.

Aucune activité n'est validée par sa seule présence ici. Écarter ou adapter les manipulations à risques (produits chimiques, courant électrique, chaleur, gaz, contact alimentaire).
