# Sources et provenance

Les sources sont référencées une seule fois et reliées aux affirmations des fiches. Catégories : [études](etudes/README.md), [recommandations](recommandations/README.md), [retours d'expérience](retours-experience/README.md).

Une recommandation institutionnelle n'est pas une preuve expérimentale. Un témoignage est une piste et non une estimation de fréquence. Chaque référence doit être vérifiable (auteurs, année, titre, DOI/URL, passage et date de contrôle). Voir [politique de preuves](../DOCUMENTATION/preuves-et-sources.md).
